# User flow screenshots

> **Historical.** These walkthroughs and screenshots were captured against an
> earlier UI (three admin tabs; before the Calendar, Rules, Scoreboard and
> Catalog tabs). The steps are broadly still right; the screenshots are not.


This folder documents the main Soulsjwa web flows. Each flow is broken into
numbered steps with a screenshot per step, so every clickable action along the
flow is depicted. Screenshots use representative local mock data, reusable page
surfaces, dialogs for focused edits, and mobile-first scoreboard cards, and
live under `screenshots/<flow>/`.
